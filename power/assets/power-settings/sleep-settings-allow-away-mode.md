# Allow away mode | Microsoft Learn

Specifies whether the system uses away mode. If this setting is disabled, away mode is not used even if programs request it.

## Aliases and setting visibility

- **Windows provisioning:**`Common\Power\Policy\Settings\Sleep\AwayMode`
- **PowerCfg:**`AWAYMODE`
- **GUID:** 25dfa149-5dd1-4736-b5ab-e8a37b5b8187
- **Description:** Allow away mode to be enabled for your computer
- **Hidden setting:** Yes

## Values

| Index | Friendly Name | Raw Value | Description |
| --- | --- | --- | --- |
| 000 | No | 0 | Don't Allow away mode to be enabled |
| 001 | Yes | 1 | Allow away mode to be enabled |

## Applies to

Available in Windows Vista and later versions of Windows.
