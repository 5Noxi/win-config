# Static configuration options for heterogeneous power scheduling overview | Microsoft Learn

You can use the static configuration options documented in this section to tune the core parking engine on heterogeneous systems.

**Note** These settings are only valid for class 1+ cores and replace `CPConcurrency`, `CPDistribution` and `CPHeadroom`.
