# Hybrid sleep | Microsoft Learn

Specifies whether the system can enter hybrid sleep.

## Aliases and setting visibility

- **Windows provisioning:**`Common\Power\Policy\Settings\Sleep\HybridSleep`
- **PowerCfg:**`HYBRIDSLEEP   `
- **GUID:** 94ac6d29-73ce-41a6-809f-6363ba21b47e
- **Description:** Allow Windows to save your work and enter a low-power state so that you can resume working almost immediately.
- **Hidden setting:** Yes

## Values

| Index | Friendly Name | Raw Value | Description |
| --- | --- | --- | --- |
| 000 | Off | 0 | Off |
| 001 | On | 1 | On |

## Applies to

Available in Windows Vista and later versions of Windows.
