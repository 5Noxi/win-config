# Low battery threshold | Microsoft Learn

Specifies a percentage of capacity when the low battery action is taken and the [low battery warning](battery-settings-low-battery-warning), if enabled, appears.

## Aliases and setting visibility

- **Windows provisioning:**`Common\Power\Policy\Settings\Battery\LowBatteryLevel`
- **PowerCfg:**`BATLEVELLOW`
- **GUID:** 8183ba9a-e910-48da-8769-14ae6dc1170a
- **Hidden setting:** Yes

## Values

The value denotes the percentage (%).

| Minimum value | 0 |
| --- | --- |
| Maximum value | 100 |

## Applies to

Available in Windows Vista and later versions of Windows.
